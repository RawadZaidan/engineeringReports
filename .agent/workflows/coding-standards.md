description: Standards and workspace initialization to perform before any coding or modification task
---

1. **Read the AI Assistance Guide**: First and always, read `AI_AGENT_ASSISTANCE.md` in the root directory to understand the project architecture, design tokens, and specific logic like signature capture.
2. **Context Check**: Verify the current state of models in `core/models.py` before suggesting any database changes.
3. **Design Alignment**: Ensure any new UI elements follow the "Premium Minimalist" aesthetic defined in the guide (Vanilla CSS, no frameworks).
4. **Environment Check**: Ensure `python manage.py runserver` is running if you need to verify changes visually.
5. **Update Knowledge Base**: Once a feature is added or modified, immediately update `AI_AGENT_ASSISTANCE.md` to reflect the changes for future sessions.
